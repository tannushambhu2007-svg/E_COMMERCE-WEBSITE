📌 About the Project

ShopEase is a modern and responsive e-commerce website developed using HTML, CSS, and JavaScript. It provides a simple and user-friendly shopping experience where users can explore products, search for items, filter products by category, and manage their shopping cart.

This project was created to practice front-end web development and improve practical programming skills.

✨ Features

- 🛒 Display products with images, names, and prices.
- 🔍 Search products by name or category.
- 📂 Filter products by category.
- ➕ Add products to the shopping cart.
- 🔢 Increase or decrease product quantities.
- ❌ Remove products from the cart.
- 💰 Automatically calculate the total price.
- 📱 Responsive design for mobile and desktop.
- 🎨 Clean and attractive user interface.

🛠️ Technologies Used

- HTML5 – For website structure.
- CSS3 – For styling and responsive design.
- JavaScript – For interactive features and shopping cart functionality.

🚀 How to Run the Project

1. Download or clone the project repository.
2. Open the project folder in Visual Studio Code.
3. Ensure all project files are in the same folder.
4. Open "index.html" in your web browser.
5. Start exploring the products and shopping cart.

🛍️ How to Use

1. Browse the available products.
2. Search for products using the search bar.
3. Filter products by category.
4. Click Add to Cart to add products.
5. Change product quantities or remove items.
6. View the total price in the shopping cart.

⚠️ Project Note

This is a front-end demonstration project. The checkout feature does not process real payments. A backend and payment gateway are required for a complete e-commerce website.
